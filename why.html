THE SHORT VERSION

Why MurOS

MurOS is a Linux-based alternative to OPNsense. Every service is built natively into the core, tested and guaranteed to work together. No plugins, no surprises.

It is built for the firewall most companies actually need: stateful filtering, NAT, routing, VPN, high availability and clean logs, all driven from a web UI on stock Debian. Free, open source, no subscription.

Install guide See every feature

The state of open source firewalls

Commercial appliances like FortiGate are polished but closed, licensed per tier, and tied to one vendor. pfSense and OPNsense fix the lock-in but lean on a large catalogue of community plugins: uneven quality, untested combinations, a compatibility matrix that can break on the next upgrade.

MurOS takes a third path.

One native core, no plugins

Every feature MurOS ships lives in the core. It is tested end to end, wired into the same web UI, and documented in the same place. There is no third-party extension system, on purpose.

Tested as a whole

Because there is no plugin matrix, the entire product can be integration-tested at every release. What ships has been run together.

A known attack surface

A fixed set of components means CVEs are trackable and patch cadence is predictable. You always know what is running on your perimeter.

Upgrades that do not break

No plugin can be left behind on an update. The package upgrades as one unit, with an automatic pre-upgrade snapshot of config and ruleset.

One consistent UI

Every page follows the same pattern: stage in the database, click Apply, push to the kernel, auto-rollback if reachability breaks. No bolted-on screens.

A focused scope, on purpose

MurOS covers what most networks actually run, natively. Here is what is in, and what stays out by design.

What you get

  • Stateful filtering, NAT, static routing and multi-WAN failover.
  • WireGuard and IPsec, with a built-in PKI for certificates.
  • HA with VRRP, conntrack sync and inter-node config replication.
  • DHCP, recursive validating DNS, monitoring, logs and notifications.
  • Everything in the default package. No edition, no paywall.

Out of scope, by design

  • No third-party plugin ecosystem to bolt on niche features.
  • No HTTP proxy or web filter with HTTPS interception, by design.
  • No gateway antivirus, supplanted by endpoint EDR.
  • No SD-WAN application steering. Multi-WAN failover covers the real need.
  • Dynamic routing, IDS/IPS and external auth are on the roadmap, not shipped yet.

Who it is for

A good fit

  • Small and mid-size companies that need a reliable perimeter firewall.
  • Admins who prefer Debian and standard Linux tooling under the hood.
  • Teams that value a tested, predictable product over a large feature catalogue.
  • Anyone replacing an end-of-life appliance without a new subscription.

Look elsewhere if

  • You need OSPF or BGP in production today.
  • You require inline IDS/IPS or deep packet inspection now.
  • You depend on a specific community plugin.
  • You want an HTTP proxy with TLS interception on the gateway.
